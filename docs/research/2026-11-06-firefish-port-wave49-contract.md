# 第四十九波施工契约：无后端的管理页转说明页（2026-11-06）

管理台里还剩六个 Firefish 页面没有任何后端支撑：实验性功能、外部整合、代理账号、广告与推广、
安全设置、其它设置。按项目规则「不得为不可用的假控件造页面」，这一波把它们变成说明页：
讲清上游有什么、这里有哪个替代入口、缺的是什么、为什么不做。

## 1. 共用组件

`components/admin/AdminUnavailable.vue`：

- 顶部警告框：标题 + 一段现状说明；
- 「这里已经有」：每项可带说明与站内链接；
- 「上游有、这里没有」：逐条列出缺口，并说明这些功能需要服务端支持，放置表单只会点了没反应。

六个页面各自只声明数据（标题、说明、已有项、缺口项），样式与结构复用组件。

## 2. 六个页面的结论

| 页面 | 已有 | 缺 |
|------|------|-----|
| 实验性功能 | 实例设置 | 实验时间线算法、前端实验开关、灰度百分比 |
| 外部整合 | MiAuth / OAuth 授权 | 第三方账号登录、外部通知转发、外部图床 |
| 代理账号 | 联邦模式 | proxyAccount 配置、独立抓取 actor |
| 广告与推广 | 实例公告 | `admin/ad/*`、按比例插入、统计 |
| 安全设置 | 注册模式、封禁用户、两步验证 | IP 封禁、邀请码管理界面、登录审计 |
| 其它设置 | 实例设置、实例 CSS、对象存储状态 | 保留用户名、远程缓存开关、字数上限、媒体代理 |

## 3. 管理台菜单

新增分组「未实现的实例功能」，六个页面各一个入口——否则这些页面只能靠手输 URL 才能看到。
分组标题本身就是提示，点进去看到的是说明而不是表单。

## 4. 有意的限制

1. 这些页面没有交互，只有说明与跳转。
2. 缺口的判定依据是当前代码里没有对应端点或表结构；将来实现其一，应把该页改成真实页面并从此
   分组移出。
3. 未新增测试。
